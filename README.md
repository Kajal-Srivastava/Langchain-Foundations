# Beginner LangChain Project – Foundations of AI Agents

📌 Overview - My first hands-on project with LangChain developed while learning through LangChain Academy. 
It is focused on understanding AI agents and LLM workflows, this project builds foundational skills for Agentic AI.

🎯 Learning Objectives
1.) Develop strong fundamentals in AI/ML and Agentic AI.
2.) Gain practical experience with LLMs and LangChain workflows.

🧠 Key Skills & Concepts Learned
1.) Managing API Keys securely using environment variables
2.) Installing & understanding core dependencies (LangChain, OpenAI SDK)
3.) Initializing a Chat Model in LangChain
4.) Invoking the model: Single Prompt → Response
5.) Understanding LLM response objects
6.) Controlling temperature & creativity of responses
7.) Creating a simple AI agent
8.) Implementing message-based interactions (HumanMessage)
9.) Streaming responses token-by-token

🛠️ Tech Stack
1.) Python – core programming language
2.) LangChain – building and orchestrating AI agents
3.) OpenAI API – LLM integration
4.) Git & GitHub – version control and project tracking
5.) Prompt Engineering – designing effective AI prompts
