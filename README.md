# 🌐 Real-Time Web Search Integration with LangChain Agents
📌 Overview  - This project demonstrates how to enhance a LangChain agent with real-time web search capabilities using the Tavily Search API. It highlights the limitations of LLM training cutoffs and shows how tool integration enables dynamic, up-to-date responses for current-event queries.

🎯 Objective
1.) Understand the limitations of static LLM training data
2.) Implement tool-calling functionality in a LangChain agent
3.) Enable real-time information retrieval using external APIs

🧠 Key Skills & Concepts Learned
1.) Identifying LLM knowledge cutoff limitations
2.) Checking model training awareness programmatically
3.) Creating custom tools using @tool decorator
4.) Integrating Tavily Search API for real-time web results
5.) Attaching tools to a LangChain agent
6.) Invoking agent queries with tool-calling capability
7.) Building dynamic, production-ready Agentic AI workflows

🛠️ Tech Stack
1.) Python – core programming language
2.) LangChain – agent creation & tool orchestration
3.) Tavily API – real-time web search integration
4.) OpenAI API – LLM reasoning engine
5.) Git & GitHub – version control and project tracking
6.) Prompt Engineering – structured query design
